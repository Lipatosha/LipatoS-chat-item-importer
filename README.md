# LipatoS - Импорт предметов

Модуль для **Foundry VTT 14** и **D&D 5e 6.0.5**, который позволяет ГМ массово создавать предметы из JSON прямо из каталога предметов.

## Версия

**1.1.1**

## Возможности

- добавляет ГМ кнопку **«Импорт предметов»** в каталог предметов;
- принимает один JSON-объект или массив предметов;
- поддерживает типы `loot`, `weapon`, `equipment`, `consumable`, `spell`, `tool`, `container`, `feat` и русские алиасы типов;
- импортирует цену и валюту, вес, редкость, описание и изображение;
- понимает русские сокращения валют: **мм, см, эм, зм, пм**;
- подставляет стандартную иконку, если `img` не указан;
- помечает созданные предметы флагом `chat-item-importer.imported`;
- работает только для ГМ.

## D&D5e 6.0.5

В версии 1.1.1 импорт приведён к актуальной структуре физических предметов D&D5e 6.0.5:

- вес записывается как `system.weight.value` + `system.weight.units`;
- редкость записывается в `system.rarities`;
- цена продолжает использовать `system.price.value` и `system.price.denomination`;
- для заклинаний и черт не добавляются поля физических предметов, которые к ним не относятся.

## Пример

```json
[
  {
    "name": "Кабаний клык",
    "type": "loot",
    "price": { "value": 3, "denomination": "sp" },
    "weight": 0.2,
    "rarity": "common",
    "description": "Крепкий клык дикого кабана."
  }
]
```

## Установка

В Foundry VTT откройте **Add-on Modules → Install Module** и вставьте:

`https://raw.githubusercontent.com/Lipatosha/LipatoS-chat-item-importer/main/module.json`

## Внутренний ID

ID модуля сохранён **`chat-item-importer`**, чтобы не нарушать совместимость с уже созданными флагами и установленной версией.
